# Athos Alves de Souza | Consultor Zendesk

Sou fundador da ATVEZA Technology. Ajudo empresas que usam Zendesk a organizar filas, SLAs e regras de atendimento, integrar o WhatsApp e aplicar automação e IA onde elas reduzem trabalho manual.

Aqui publico extensões, demonstrações e guias técnicos para administradores Zendesk e equipes de atendimento.

## Projetos e guias técnicos

| Projeto | O que você pode fazer |
| --- | --- |
| [Transcrição de áudio do WhatsApp no Zendesk](https://github.com/athossouza/zendesk-whatsapp-audio-transcriber) | Ler e salvar transcrições no ticket. A extensão do Chrome roda o Whisper localmente no navegador. |
| [WhatsApp Individual no Zendesk](https://github.com/athossouza/zendesk-whatsapp-individual) | Criar, com o Zendesk App Builder, um app para enviar templates aprovados e outro para consultar o histórico no ticket. |
| [HerculesBotV2](https://github.com/athossouza/HerculesBotV2) | Explorar a arquitetura de um agente de IA para suporte técnico, integrado ao Zendesk e WhatsApp, com transferência para atendimento humano. |
| [Zendesk Screen Pop Simulator](https://github.com/athossouza/zendesk-screen-pop-simulator) | Testar a abertura automática de tickets em fluxos de telefonia CTI com o Zendesk Talk Partner Edition. |
